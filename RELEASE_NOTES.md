# STITCH — первый релиз

Бот на деморган GTA5RP для мини-игры с футболкой.

**Установка:** скачайте `STITCH.zip`, распакуйте его и запустите `STITCH.exe`. Python не требуется.

**Управление:** сначала откройте мини-игру клавишей **E**, затем используйте **F6** для запуска или паузы. **F8** закрывает приложение.

**Возможности:** последовательность нажатий от 1 до 20, пауза при переключении окна, настройка скорости и темы, мини-окно состояния, таймер со звуковым уведомлением, счётчик нажатий и журнал диагностики.

**Требования:** Windows 10/11 x64; основной монитор и игра 1920 × 1080; оконный режим без рамки.

**SHA-256 файла `STITCH.exe`:** `59DC9CAA61DB3B8AB06FF2D0A2251046A0CB827B0F8E28662848C8380AD25536`

STITCH — моя программа. Если хотите проверить скачанный файл, просканируйте его установленным антивирусом и сравните SHA-256 с указанным выше. Совпадение хеша подтверждает целостность файла, но не заменяет проверку на вирусы.
