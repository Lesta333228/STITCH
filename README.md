# STITCH — бот на деморган GTA5RP

**Программа для Windows · ГТА 5 РП · мини-игра с футболкой**

STITCH — бот для деморгана GTA5RP (ГТА 5 РП). Программа выполняет последовательность нажатий в мини-игре с футболкой у швейного станка. Запуск, пауза и выход управляются горячими клавишами. При переключении на другое окно нажатия приостанавливаются.

> Неофициальный проект. Не связан с разработчиками GTA5RP. Перед использованием проверьте правила сервера.

## Скачать бота на деморган GTA5RP

Скачайте `STITCH.zip` на странице [Releases](../../releases/latest), распакуйте архив и запустите `STITCH.exe`. Python и установка библиотек не требуются. При первом запуске распаковка ресурсов может занять время.

## Быстрый старт

1. Запустите `STITCH.exe`.
2. Подойдите к швейному станку и нажмите **E**, чтобы открыть мини-игру.
3. После открытия мини-игры нажмите **F6** для запуска или паузы бота.
4. Нажмите **F8**, чтобы закрыть приложение.

Если нажать F6 до открытия мини-игры клавишей E, бот не начнёт работу.

## Функции бота

- Автоматическая последовательность нажатий: `1 → 2 → 2 → 3 → 3 → … → 19 → 19 → 20`.
- **F6** — запуск и пауза; **F8** — выход.
- Пауза при переключении на другое окно.
- Настройка скорости и темы оформления.
- Необязательное мини-окно состояния.
- Настраиваемый таймер со звуковым уведомлением; его можно отключить.
- Счётчик отправленных нажатий и журнал диагностики.

## Системные требования

- Windows 10/11, 64-битная версия.
- Основной монитор и игра: 1920 × 1080.
- Игра в оконном режиме без рамки.

В эксклюзивном полноэкранном режиме мини-окно состояния не отображается.

## Настройки и поддержка

Рекомендуемое время таймера — 50 секунд. Счётчик показывает отправленные нажатия, а не подтверждённый результат в игре.

Настройки и журнал диагностики находятся в `%LOCALAPPDATA%\STITCH`. При сообщении об ошибке приложите `stitch.log` из этой папки. Для связи: [Discord](https://discord.gg/f8cAs2gfEG).

Подробности есть в [инструкции](STITCH_инструкция.pdf), которая также входит в архив релиза.

## Проверка файла

STITCH — моя программа. Если хотите самостоятельно проверить скачанный файл, просканируйте его установленным антивирусом и сравните SHA-256 файла `STITCH.exe` с указанным ниже:

```text
59DC9CAA61DB3B8AB06FF2D0A2251046A0CB827B0F8E28662848C8380AD25536
```

Совпадение SHA-256 подтверждает, что ваш файл соответствует опубликованной сборке; само по себе оно не является проверкой на вирусы.
